# Spike findings

Time-boxed investigations that resolve an open item from `game-design/16_DECISION_LOG.md` Part B. Each document records the verdict, the evidence behind it, and what remains unverified — so the milestone that consumes the ruling does not have to re-research it.

A spike is not a feature. Its output is a decision **plus the failures encountered on the way** — the failures are the point, because they are what CI will hit. Throwaway code lives under `spikes/`.

| [O14 — AppLovin MAX Godot: S2S rewarded callbacks & `setUserId`](O14-applovin-max-s2s.md) | **O14** (`12` §3.3) | M0-04 | 2026-08-11 | ✅ **Proceed, no plugin patch.** `setUserId` is absent from every layer, but `show_rewarded_ad(..., custom_data)` is wired end-to-end and populates `{CUSTOM_DATA}` in the S2S postback — a better, per-impression attribution channel. `IRewardedAdPort` survives unchanged. | [O23 (iOS leg) — Godot 4 C#/.NET iOS export via the CocoaPods/Xcode path](O23-godot-ios-export.md) | **O23** (`14` §1) | M0-05b | 2026-08-11 | 🔒 **NOT EXECUTED — O23 remains open.** No Mac, no Apple Developer account, so this is a source-and-docs recipe, not a build. Four things *are* settled by reading the 4.7.1-stable engine: a non-macOS runner **cannot** export .NET to iOS (hard `return false`); the path *is* scriptable, and in fact produces an `.ipa` by default; iOS C# is **NativeAOT + trimming**, a different runtime from every other target and the risk most likely to reopen D1; and the missing-`.sln` silent failure has an iOS twin with a different tell. Also found: an unfixed, **closed-as-not-planned** .NET-only launch crash against **4.7.1 exactly** ([#121736](https://github.com/godotengine/godot/issues/121736)), headless CI export open-broken since 2023 ([#76749](https://github.com/godotengine/godot/issues/76749)), and a live engine bug where the release provisioning-profile env var is never read. `12` §3.2 is wrong about CocoaPods — Godot never emits a Podfile. 🔴 **The AppLovin MAX plugin is a dead dependency on iOS**: unfixed build (#61) *and* runtime-init (#60) breakage on 4.5, no maintainer since 2025-04, three Godot minors behind our pin. Five costed fallbacks recorded. |
